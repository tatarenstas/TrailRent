# Lab 03 verification notes

- `CatalogDbContext` and all six `IEntityTypeConfiguration<T>` mappings are in `TrailRent.Catalog.Dal`.
- `Migrations/` contains the initial migration and `db/initial-catalog.sql` is generated by `dotnet ef migrations script --idempotent`.
- `EquipmentRepository.GetWithDetailsAsync` demonstrates eager `Include/ThenInclude`; `EquipmentCategoryRepository.GetWithEquipmentAsync` demonstrates explicit loading; `EquipmentFeatureRepository.GetEquipmentByFeatureSinceAsync` filters the explicit many-to-many join entity.
- `EquipmentFilterSpecification` and `RentableEquipmentSpecification` are two independent specifications. Filtering, sorting and paging are evaluated before `ToListAsync`.
- Development startup calls `MigrateAsync` and the idempotent program seed; category and feature dictionaries use fixed IDs through `HasData`.
- Swagger exposes 200, 201, 204, 400, 404 and 409 responses. `ApiExceptionHandler` writes one structured error log per exception and returns RFC-style ProblemDetails.

For the visual demonstration requested by the assignment, start the API using the README, then capture Swagger, a paginated `/api/equipment` response, an invalid POST (400), and the console SQL logs from `/api/equipment/1` versus `/api/categories/1`.
